# Velox Benchmarks & Methodology (Phase 20)

All measurements reported here were collected on an unmodified Windows 11 host with **WHPX + Hyper-V + VBS enabled**, no overclocking, no OS security weakening, no benchmark tampering, and exact output/FNV-1a checksum validation on every benchmark run.

## 1. Reference Test Environment

- **CPU**: Intel Core Ultra 7 265KF (8 P-cores + 12 E-cores, 20 logical CPUs)
- **GPU**: NVIDIA GeForce RTX 5070 Ti 16 GB (Driver 610.88)
- **Memory**: 96 GB DDR5-6000 (16 GiB guest RAM, guest THP `always_nodefrag`)
- **Storage**: NVMe SSD (`cache=writeback` + verified guest flush propagation, `aio=native`, 4 virtio-blk queues; `cache=unsafe` prohibited)
- **Host OS**: Windows 11, WHPX + Hyper-V + VBS enabled
- **Guest OS**: Official Android 17 (API 37, Google APIs, `x86_64`)
- **Runtime**: Velox Phase 20 integrated build (gfxstream Patch 0031 + QEMU Patches 0016–0019 + `20_PE_rpe` topology)

## 3. Multi-Objective Topology Analysis (Pareto Frontier)

Data artifact: [`benchmarks/results/phase20/multi_objective_pareto.json`](../benchmarks/results/phase20/multi_objective_pareto.json) (generated by [`scripts/phase20_multi_objective.py`](../scripts/phase20_multi_objective.py)).

Across 6 hybrid topologies (`8P`, `12_PE`, `16_PE`, `18_soft_rpe`, `20_auto`, `20_PE_rpe`):
- **`20_PE_rpe`** (`cores=20, affinity=PE, thread_placement={"render":"PE","prefetch":"P"}`) is the **unique Pareto-optimal point** on `[CPU MT, GPU Sync, 120fps 1% Low]`, strictly dominating all 5 alternatives.
- **`8P`** remains an optional extreme for single-thread RAM throughput (**95.2%** native) and minimum 64 MiB random latency (**110.7 ns**).
- **Storage vs. Frame-Pacing Trade-off**: Disabling `VELOX_HIGHRES_POLL=0` lowers 4K durable `fsync` P50 from **5.00 ms to 4.44 ms** (+8.8% small-file create/fsync) at the expense of 120 fps 1% Low pacing (119.58 → 106.4 fps); dedicated storage/CPU profiles set `VELOX_HIGHRES_POLL=0`.
